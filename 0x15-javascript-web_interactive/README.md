# 0x15. JavaScript - Web jQuery Part 1

## Description

This project introduces DOM manipulation and event handling using vanilla JavaScript.

## Learning Objectives

- Select HTML elements using the DOM API.
- Change text colors and text content.
- Handle click events with addEventListener().
- Add and toggle CSS classes.
- Create and append HTML elements dynamically.
- Update a webpage without reloading it.

## Tasks

- 0: Turn the header red.
- 1: Change all paragraph text to blue.
- 2: Turn the header red on click.
- 3: Add a CSS class on click.
- 4: Toggle between red and green classes.
- 5: Add a list item on click.
- 6: Change the header text on click.

## Requirements

- Use vanilla JavaScript only.
- Do not use var.
- Do not import external libraries.
- End all files with a newline.
