# 0x12. JavaScript - Warm up

## Description

This project is a warm-up to JavaScript for SE 300: High-Level Programming II.
It covers the basics of the language: variables, `console.log`, command-line
arguments (`process.argv`), type conversion, loops, and arrays - all written
without `var`, and validated with `semistandard`.

## Requirements

- All files are interpreted using Node.js (version 14.x)
- All files start with `#!/usr/bin/node`
- All files are executable
- Code follows `semistandard` style (Standard rules + semicolons)
- `var` is not used anywhere in this project

## Tasks

| File | Description |
| --- | --- |
| `0-javascript_is_amazing.js` | Prints `JavaScript is amazing` using a constant |
| `1-multi_languages.js` | Prints three languages on three lines |
| `2-arguments.js` | Prints a message based on the number of arguments passed |
| `3-value_argument.js` | Prints the first argument passed, or `No argument` |
| `4-concat.js` | Prints two arguments in the format `<first> is <second>` |
| `5-to_integer.js` | Converts the first argument to an integer, or prints `Not a number` |
| `6-multi_languages_loop.js` | Prints three languages using an array and a loop |
| `7-multi_c.js` | Prints `C is fun` a given number of times using a loop |
| `8-square.js` | Prints a square of `X` characters of a given size |
